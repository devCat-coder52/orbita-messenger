# Мемы для ролика — пересборка в 1080p

Исходники вытащены прямо из `Orbita.vproj` (они лежат внутри проекта). Подписи
на них были запечены в низком разрешении: 604×552, 640×480, 728×695. Здесь они
пересобраны: текст перерисован заново крупным шрифтом, картинка апскейлена
с мягким шафом.

Скриншот с Кириллом и Мефодием не трогал — как просили.

## Файлы

На каждый мем по три файла:

| Файл | Что это | Когда брать |
|---|---|---|
| `*_full_1920.png` | 1920×1080, тёмный брендовый фон, готовый кадр | вставить в таймлайн как есть, на 100 % |
| `*_card_1920.png` | 1920×1080, прозрачный фон, карточка с тенью | положить поверх своего фона или видео |
| `*_raw_1080.png` | сам мем высотой 1080 (ширина разная) | если нужно заполнить кадр целиком или обрезать |

## Что именно переделано

- **Мороженое и wi-fi.** Полоса-подпись перерисована на чистом фоне
  (цвет взят из исходника, 74/114/121), текст — Segoe UI Semibold, две строки,
  белый. Рельеф апскейлен в 1,65× и подшарплен.
- **Переместиться в Египет.** Белая полоса пересобрана по высоте текста,
  шрифт Arial Black, две строки в верхнем регистре плюс «Я:» слева. Картинка
  апскейлена в 1,99×.
- **Совсем другая история.** Фото апскейлено в 1,88×, старая подпись закрыта
  чёрной плашкой (начинается выше текста и ниже подбородка), новая — Arial
  Black, две строки по центру.

Внутренний апскейл картинки остался 1,7–1,9× — это предел исходников. Зато
текст теперь векторно-чистый, а не мыло из 450 пикселей.

## Как пересобрать

```powershell
python rebuild_memes.py    # перезапишет все девять PNG
```

Скрипт `rebuild_memes.py`: размеры полос, шрифты и отступы — константы вверху
функций `card_m1`, `card_m2`, `card_m3`.
